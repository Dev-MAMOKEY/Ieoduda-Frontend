# 외부 파트너 증빙 검토

기능: 외부 법무·장례 파트너가 공식 증빙을 사람의 판단으로 승인·반려합니다.
대상: 외부 법무·장례 파트너
분류: Web Browser

#### **진입 조건**

지정된 파트너 검토자가 보안 포털에 인증하면 진입합니다.

#### **표시 요소**

검토에 필요한 대상자 정보, 증빙 원본, 제출 시각, 승인·반려·추가자료 요청과 검토 메모를 표시합니다. 역할별 패키지는 표시하지 않습니다.

#### **사용자 액션**

파트너가 검토 결과를 기록합니다.

#### **API 호출**

- 검토 대상 조회: `GET /api/partner/reviews/{reviewId}`
- 결과 제출: `POST /api/partner/reviews/{reviewId}/decision`

#### **예외 처리**

AI 자동 승인 기능을 제공하지 않습니다. 이해충돌 또는 권한 만료 시 다른 검토자에게 재배정합니다.
