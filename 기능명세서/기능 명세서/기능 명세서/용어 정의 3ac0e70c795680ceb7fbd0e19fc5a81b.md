# 용어 정의

기능: 실제 사후 이메일 인계에 사용되는 계획, 담당자, 확인자, 증빙과 단계 발송 개념을 정의합니다.
분류: Definition

개발 과정에서 혼선이 없도록 핵심 용어를 먼저 정의합니다.

#### **Plan(유고 계획)**

작성자가 생전에 가족·관계·업무 영역의 처리 의도, 담당자, 공개 범위와 실행 순서를 정리한 계획입니다.

#### **Plan Version(계획 버전)**

담당자, 공개 범위, 행동 또는 실행 순서가 변경될 때 생성되는 불변 버전입니다. 실제 사후 사건은 특정 승인 버전을 기준으로 진행합니다.

#### **Recipient(역할 담당자)**

사망 후 역할별 인계 이메일을 받는 가족·지인·업무 관계자입니다. 생전에 이메일을 검증하고 역할을 수락해야 합니다.

#### **Confirmer(지정 확인자)**

작성자의 사망 발생을 서로 독립적으로 신고하는 사람입니다. 최소 2명이 필요하며 역할별 패키지 열람 권한은 없습니다.

#### **Dispute Contact(이의 제기 연락처)**

대기 기간 시작 이메일을 받고 오신고·사칭·분쟁을 신고할 수 있는 사람입니다. 패키지를 열람할 수 없습니다.

#### **Evidence Review Partner(증빙 검토 파트너)**

공식 증빙을 검토하는 외부 법무·장례 파트너입니다. 승인·반려·추가자료 요청을 기록하지만 전체 계획은 볼 수 없습니다.

#### **Release Case(사후 인계 사건)**

두 확인자의 신고부터 증빙 검토, 대기 기간, 이의 제기와 단계별 발송까지 하나로 관리하는 사건입니다.

#### **Role Package(역할별 패키지)**

담당자가 맡은 행동을 수행하는 데 필요한 정보만 담은 사후 인계 화면입니다. 이메일 본문에 직접 포함되지 않습니다.

#### **Release Stage(발송 단계)**

선행 작업 완료 여부에 따라 순서대로 활성화되는 역할별 이메일 발송 단위입니다.

#### **Living Handoff Check(생전 인계 점검)**

담당자 이메일 도달, 역할 수락과 공개 범주 이해만 확인하는 선택 기능입니다. 실제 사후 패키지 전문은 공개하지 않습니다.
