# 증빙 보관 및 삭제 정책

기능: 공식 증빙은 보안 화면으로만 받고 파트너 검토 완료 후 30일 이내 원본을 삭제합니다.
분류: Definition

#### **수집**

이메일 첨부를 허용하지 않고 보안 제출 화면에서만 받습니다. 실제 인정 증빙 종류는 외부 파트너와 법률 검토 후 확정합니다.

#### **접근**

외부 파트너의 지정 검토자에게 필요한 기간과 범위만 접근 권한을 부여합니다.

#### **삭제**

검토 완료일을 기준으로 30일 이내 원본 파일을 삭제합니다. 분쟁 보존이 법적으로 필요한 경우 자동 연장하지 않고 별도 법적 근거와 감사 기록을 요구합니다.

#### **영구 감사 기록**

제출 시각, 검토 파트너, 결과, 완료 시각, 삭제 예정·완료 시각, 증빙 종류와 원본이 아닌 무결성 해시만 유지합니다.
