# 대기·이의 제기 설정

기능: 7~30일 대기 기간과 절차를 중지할 이의 제기 이메일 연락처를 설정합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

확인자 등록 후 진입합니다.

#### **표시 요소**

대기 기간 선택, 작성자 본인 경고 이메일, 이의 제기 연락처, 취소 절차와 분쟁 시 자동 중지 안내를 표시합니다.

#### **사용자 액션**

대기 기간과 연락처를 저장하고 이메일을 검증합니다.

#### **API 호출**

설정 저장: `PUT /api/plans/{planId}/release-policy`

연락처 검증: `POST /api/dispute-contacts/{id}/verification-email`

#### **예외 처리**

검증되지 않은 이의 제기 연락처는 활성화하지 않습니다.
