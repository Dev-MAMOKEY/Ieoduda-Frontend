# 서비스 안내 / 안전 동의

기능: 실제 사후 이메일 인계의 조건과 한계를 확인하고 계획 작성을 시작합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

회원가입 완료 후 또는 계획이 없는 상태로 로그인하면 진입합니다.

#### **표시 요소**

서비스 한 줄 설명: “사망이 안전하게 확인되면, 가족과 동료에게 필요한 일을 올바른 순서로 이메일로 전달합니다.”

금지정보 안내 카드: “비밀번호를 적지 마세요. 계정 이름, 자료 위치의 유형과 원하는 처리 결과만 작성합니다.”

#### **실제 사후 인계 안내**

- 지정 확인자 2명의 신고가 필요합니다.
- 외부 법무·장례 파트너가 공식 증빙을 검토합니다.
- 승인 후 7~30일의 취소 가능한 대기 기간을 거칩니다.
- 이메일에는 민감 내용을 넣지 않고 보안 링크만 발송합니다.
- 서비스가 실제 계정을 자동 삭제·이전하지 않습니다.
- 필수 동의 체크박스와 시작 버튼을 표시합니다.

#### **사용자 액션**

안내와 데이터 처리 범위를 확인한 뒤 새 계획 만들기로 이동합니다.

#### **API 호출**

- 동의 기록: `POST /api/consents`

#### **예외 처리**

필수 동의 없이 시작하면 “사후 인계 조건과 안전 범위를 확인해 주세요”를 표시합니다.
