# 삶의 구역 작성

기능: 가족·관계·업무에 대한 희망을 자연어로 작성하고 AI 구조화를 요청합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

계획 생성 후 또는 계획 홈의 구역을 선택하면 진입합니다.

#### **표시 요소**

자연어 입력, 금지정보 안내, AI 구조화 버튼과 직접 항목 추가 버튼을 표시합니다.

예시: “아내에게 가족사진 위치를 알려주고, 민수에게 디자인 프로젝트를 인계한 뒤, 지수에게 SNS와 클라우드 정리를 부탁하고 싶어요.”

#### **사용자 액션**

희망을 작성하고 OpenAI API에 전달할 원문 범위를 확인한 뒤 구조화를 요청합니다.

#### **API 호출**

- 원문 저장: `POST /api/plans/{planId}/statements`
- AI 구조화: `POST /api/plans/{planId}/compile`

#### **예외 처리**

자격증명 의심 입력을 저장·전송하지 않고 위치 유형만 적도록 안내합니다.
