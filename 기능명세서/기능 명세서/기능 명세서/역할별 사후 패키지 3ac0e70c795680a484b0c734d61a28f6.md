# 역할별 사후 패키지

기능: 인증된 담당자가 자신의 역할에 필요한 대상·행동·순서만 확인합니다.
대상: 역할 담당자
분류: Web Browser

#### **진입 조건**

사후 이메일 확인을 통과하면 진입합니다.

#### **표시 요소**

역할, 대상 이름, 위치 유형, 행동, 선행 완료 상태, 공식 절차 출처와 완료·문제 신고 버튼을 표시합니다.

다른 역할의 정보와 자격증명은 표시하지 않습니다.

#### **사용자 액션**

담당자가 각 행동을 확인하고 단계 완료 또는 문제를 신고합니다.

#### **API 호출**

- 패키지 조회: `GET /api/posthumous-packages/{accessSessionId}`
- 행동 완료: `POST /api/posthumous-packages/{id}/actions/{actionId}/complete`
- 문제 신고: `POST /api/posthumous-packages/{id}/issues`

#### **예외 처리**

다른 역할 접근, 캡처된 만료 URL과 권한 없는 객체 요청을 차단합니다. 실제 외부 계정 작업은 서비스가 대신 실행하지 않습니다.
