# 새 계획 만들기

기능: 계획 이름과 사후 공개 대기 기간을 정하고 기본 인계 구역을 생성합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

서비스 안내에서 시작하거나 계획 홈에서 새 계획을 선택하면 진입합니다.

#### **표시 요소**

- 계획 이름
- 기본 구역: 가족, 관계 정리, 업무 연속성
- 대기 기간: 7~30일
- 이의 제기 연락처 등록 안내

#### **사용자 액션**

계획 이름과 대기 기간을 입력해 초안을 생성합니다.

#### **API 호출**

- 계획 생성: `POST /api/plans`

#### **예외 처리**

7일 미만 또는 30일 초과 값을 저장하지 않습니다.
