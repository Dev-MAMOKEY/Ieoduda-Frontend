# 사후 인계 이메일

기능: 활성화된 단계의 담당자가 만료 링크와 별도 이메일 OTP 확인 후 패키지에 접근합니다.
대상: 역할 담당자
분류: Web Browser

#### **진입 조건**

대기 기간 종료와 선행 단계 완료 후 사후 인계 이메일을 받으면 진입합니다.

#### **표시 요소**

역할명, 링크 만료, OTP 요청, 피싱 방지 안내와 공식 문의 주소를 표시합니다. 인증 전에는 인계 내용을 표시하지 않습니다.

#### **사용자 액션**

첫 이메일의 링크를 열고 두 번째 이메일의 OTP를 입력합니다.

#### **API 호출**

- 링크 검증: `GET /api/posthumous-access/{token}`
- OTP 발송: `POST /api/posthumous-access/{token}/otp`
- OTP 확인: `POST /api/posthumous-access/{token}/verify`

#### **예외 처리**

만료, 재사용, 반복 실패와 역할 불일치를 차단합니다. 같은 이메일 기반 두 단계 확인이라는 한계를 안내합니다.
