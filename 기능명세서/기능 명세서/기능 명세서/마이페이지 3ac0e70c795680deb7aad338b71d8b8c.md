# 마이페이지

기능: 계정, 계획, 이메일 검증, 담당자·확인자 상태와 삭제를 관리합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

로그인 후 마이페이지를 선택하면 진입합니다.

#### **표시 요소**

이메일, 계획 버전, 담당자 수락, 확인자 수락, 이의 제기 연락처, 대기 기간, 로그아웃, 계획 비활성화와 계정 삭제를 표시합니다.

#### **사용자 액션**

이메일 변경 시 모든 관련 역할을 재검증합니다. 계획을 비활성화하거나 계정을 삭제할 수 있습니다.

#### **API 호출**

- 내 정보: `GET /users/me`
- 이메일 변경: `PUT /users/me/email`
- 계획 비활성화: `POST /api/plans/{planId}/deactivate`
- 계정 삭제: `DELETE /users/me`

#### **예외 처리**

진행 중 사후 사건이 있으면 단순 삭제 대신 사건 동결과 법률·운영 검토 절차를 안내합니다.
