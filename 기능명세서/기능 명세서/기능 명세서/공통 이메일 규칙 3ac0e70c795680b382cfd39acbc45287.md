# 공통 이메일 규칙

기능: 모든 연락은 이메일로 보내되 민감 내용은 본문이 아닌 만료형 보안 화면에서만 공개합니다.
분류: Definition

#### **이메일 본문**

이메일에는 서비스명, 역할명, 필요한 다음 행동, 링크 만료 시각, 보안 링크, 피싱 방지 안내와 문의 주소만 표시합니다.

대상 목록, 개인 메시지, 자료 위치, 업무 세부사항과 증빙 원본은 이메일 본문이나 첨부파일로 보내지 않습니다.

#### **링크 정책**

- 만료형 링크
- 1회성 또는 제한 횟수 사용
- 토큰 평문 미저장
- 전달·재사용·반복 실패 차단
- 이메일 주소 변경 시 기존 수락과 링크 무효화

#### **사후 열람 확인**

담당자는 첫 이메일의 보안 링크를 연 뒤 별도 이메일로 받은 OTP를 입력해야 합니다. 같은 이메일 계정에 의존하므로 엄밀한 다중요소 인증이 아닌 2단계 이메일 확인입니다.

#### **반송 정책**

- 일시 반송: 제한 횟수 재시도
- 영구 반송: 해당 단계 중지
- 역할 최대 대기 초과: 사전 수락한 대체 담당자로 전환
- 대체 담당자 없음: 자동으로 다음 단계 진행 금지
