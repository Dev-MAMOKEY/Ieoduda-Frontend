# 계획 홈

기능: 계획 준비 상태, 담당자 수락, 확인자, 충돌과 실제 사후 사건 상태를 한곳에서 확인합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

로그인 후 계획이 존재하면 진입합니다.

#### **표시 요소**

- 가족·관계·업무 구역
- 담당자 이메일 수락 상태
- 확인자 2명 등록 상태
- 대체 담당자 누락
- 해결되지 않은 충돌
- 선택한 대기 기간
- 실제 사후 사건 상태

종합 AI 준비도 점수는 제공하지 않습니다.

#### **사용자 액션**

계획 작성, 담당자 관리, 발송 순서, 인계 점검과 사건 상태로 이동합니다.

#### **API 호출**

- 계획 요약: `GET /api/plans/current/summary`
- 사후 사건 상태: `GET /api/release-cases/current`

#### **예외 처리**

조회 실패 시 최신 여부를 표시하고 재시도합니다.
