# 사망 신고 이메일

기능: 지정 확인자 2명이 서로 독립적으로 작성자의 사망을 신고합니다.
대상: 지정 확인자
분류: Web Browser

#### **진입 조건**

생전에 검증된 확인자가 신고 안내 이메일 또는 자신의 확인자 링크로 진입합니다.

#### **표시 요소**

작성자 식별 정보, 신고 책임, 허위 신고 경고, 사건 기본 정보와 신고 버튼을 표시합니다.

#### **사용자 액션**

각 확인자가 독립적으로 신고합니다. 다른 확인자의 신고 내용은 볼 수 없습니다.

#### **API 호출**

- 신고 시작: `POST /api/death-reports`
- 확인자 신고: `POST /api/death-reports/{caseId}/confirm`

#### **예외 처리**

두 신고가 불일치하면 절차를 중지하고 운영 검토로 전환합니다. 한 명의 신고만으로 공개하지 않습니다
