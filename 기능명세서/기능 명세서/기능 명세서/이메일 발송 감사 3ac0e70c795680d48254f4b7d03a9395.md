# 이메일 발송 감사

기능: 발송·반송·열람·인증·취소 이력을 내용 노출 없이 추적합니다.
대상: 서비스 운영자
분류: Web Browser

#### **진입 조건**

권한 있는 운영자가 사후 사건의 전달 상태를 조회하면 진입합니다.

#### **표시 요소**

수신자 역할, 이메일 마스킹, 발송·반송·재시도·열람·OTP 실패·완료 시각과 메시지 식별자를 표시합니다. 이메일 본문과 패키지 전문은 표시하지 않습니다.

#### **사용자 액션**

운영자는 재시도 정책 실행, 사건 동결과 파트너 문의만 수행합니다.

#### **API 호출**

- 발송 감사: `GET /api/admin/release-cases/{caseId}/email-deliveries`
- 사건 동결: `POST /api/admin/release-cases/{caseId}/freeze`

#### **예외 처리**

운영자가 분쟁 상태를 단독 해제하거나 패키지 내용을 열람할 수 없습니다.
