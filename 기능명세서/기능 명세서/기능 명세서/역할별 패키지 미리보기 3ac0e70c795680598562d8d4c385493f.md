# 역할별 패키지 미리보기

기능: 사후 이메일 인증 후 각 담당자에게 공개될 정보와 행동을 생전에 검토합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

역할과 발송 순서가 확정되면 진입합니다.

#### **표시 요소**

역할별 대상, 위치 유형, 행동, 선행 조건과 제외 정보를 표시합니다.

#### **사용자 액션**

불필요한 항목을 제거하고 패키지 버전을 승인합니다.

#### **API 호출**

- 미리보기: `GET /api/plans/{planId}/packages/preview`
- 승인: `POST /api/plans/{planId}/packages/seal`

#### **예외 처리**

비밀번호, 근거 없는 항목과 과도한 권한이 있으면 봉인을 차단합니다.
