# 지정 확인자 등록

기능: 사망을 독립 신고할 확인자 2명 이상을 이메일로 등록하고 책임 수락을 받습니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

계획 작성 중 확인자 설정 단계에서 진입합니다.

#### **표시 요소**

확인자 이름, 이메일, 관계, 책임 안내와 수락 상태를 표시합니다.

#### **사용자 액션**

최소 2명의 확인자를 등록하고 이메일 수락을 요청합니다.

#### **API 호출**

- 확인자 등록: `POST /api/plans/{planId}/confirmers`
- 수락 이메일: `POST /api/confirmers/{id}/acceptance-email`

#### **예외 처리**

수락 완료 확인자가 2명 미만이면 계획을 사후 공개 가능 상태로 봉인할 수 없습니다.
