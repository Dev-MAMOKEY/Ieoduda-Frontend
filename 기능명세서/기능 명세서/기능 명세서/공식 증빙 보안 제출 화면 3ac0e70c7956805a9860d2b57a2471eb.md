# 공식 증빙 보안 제출 화면

기능: 공식 증빙은 이메일 첨부가 아닌 암호화된 보안 화면으로 제출합니다.
대상: 지정 확인자
분류: Web Browser

#### **진입 조건**

두 확인자의 신고가 일치하면 제출 안내 이메일을 통해 진입합니다.

#### **표시 요소**

파트너가 인정하는 증빙 유형, 파일 제한, 보관·삭제 일정, 제출 동의와 업로드 영역을 표시합니다.

#### **사용자 액션**

증빙을 제출하고 파트너 검토로 전달합니다.

#### **API 호출**

- 업로드 세션: `POST /api/release-cases/{caseId}/evidence/upload-session`
- 제출 완료: `POST /api/release-cases/{caseId}/evidence/submit`

#### **저장 위치 요약**

원본은 암호화 증빙 저장소에 보관하고 PostgreSQL에는 메타데이터와 접근 감사 기록을 저장합니다.

#### **예외 처리**

이메일 첨부 접수를 지원하지 않습니다. 악성 파일 검사 실패와 형식 오류 시 파트너에게 전달하지 않습니다.
