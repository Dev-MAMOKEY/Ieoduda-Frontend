# 선택형 생전 인계 점검

기능: 실제 내용을 공개하지 않고 담당자 이메일 도달과 역할 이해만 선택적으로 확인합니다.
대상: 계획 작성자, 역할 담당자
분류: Web Browser

#### **진입 조건**

작성자가 봉인된 계획에서 인계 점검을 선택하면 진입합니다.

#### **표시 요소**

이메일 도달, 역할 수락, 공개 범주 이해, 대체 담당자와 문의 사항만 표시합니다.

#### **사용자 액션**

작성자가 점검 이메일을 보내고 담당자는 역할 이해 여부를 답합니다.

#### **API 호출**

- 점검 발송: `POST /api/plans/{planId}/handoff-checks`
- 점검 응답: `POST /api/handoff-checks/{token}/respond`

#### **예외 처리**

실제 사후 패키지 전문과 민감 위치는 공개하지 않습니다.
