# 단계 완료 / 대체 담당자

기능: 선행 단계 완료를 확인하고 무응답·반송 시 사전 수락한 대체 담당자로 전환합니다.
대상: 서비스 운영자, 역할 담당자
분류: Web Browser

#### **진입 조건**

단계 완료, 최대 대기 초과, 영구 반송 또는 문제 신고가 발생하면 진입합니다.

#### **표시 요소**

현재 단계, 완료 조건, 남은 시간, 반송·무응답 상태, 대체 담당자와 다음 단계 잠금 상태를 표시합니다.

#### **사용자 액션**

담당자는 완료 또는 문제를 보고합니다. 시스템은 정책에 따라 대체 담당자에게 이메일을 발송합니다.

#### **API 호출**

- 단계 상태: `GET /api/release-cases/{caseId}/stages/{stageId}`
- 대체 전환: `POST /api/release-cases/{caseId}/stages/{stageId}/fallback`

#### **예외 처리**

대체 담당자가 없으면 다음 단계를 자동 활성화하지 않고 사건을 차단 상태로 유지합니다.
