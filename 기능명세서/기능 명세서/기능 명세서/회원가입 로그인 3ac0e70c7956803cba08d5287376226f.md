# 회원가입 / 로그인

기능: 작성자가 계정을 만들거나 로그인해 자신의 유고 계획에 접근합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

앱 최초 진입 또는 로그아웃 상태에서 진입합니다.

#### **표시 요소**

회원가입 탭에는 이메일, 비밀번호, 비밀번호 확인과 회원가입 버튼을 표시합니다.

로그인 탭에는 이메일, 비밀번호와 로그인 버튼을 표시합니다.

#### **사용자 액션**

회원가입 완료 후 계획이 없으면 서비스 안내 화면으로, 계획이 있으면 계획 홈으로 이동합니다.

#### **API 호출**

- 회원가입: `POST /auth/signup`
- 로그인: `POST /auth/login`
- 로그아웃: `POST /auth/logout`

#### **예외 처리**

이메일 중복과 형식 오류를 필드 아래 표시합니다. 로그인 실패 시 계정 존재 여부를 구분하지 않습니다.
