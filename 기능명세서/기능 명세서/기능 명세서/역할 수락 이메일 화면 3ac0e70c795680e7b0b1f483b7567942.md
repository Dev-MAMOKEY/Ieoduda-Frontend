# 역할 수락 이메일 / 화면

기능: 담당자가 생전에 이메일을 인증하고 사후에 맡을 역할과 공개 범주를 수락합니다.
대상: 역할 담당자
분류: Web Browser

#### **진입 조건**

작성자가 발송한 역할 수락 이메일의 만료 링크로 진입합니다.

#### **표시 요소**

작성자 이름, 역할명, 공개될 정보의 범주, 책임 범위, 수락·거절 버튼과 문의 주소를 표시합니다. 실제 패키지 전문은 공개하지 않습니다.

#### **사용자 액션**

이메일 소유권을 확인하고 역할을 수락 또는 거절합니다.

#### **API 호출**

- 초대 조회: `GET /api/recipient-acceptances/{token}`
- 수락: `POST /api/recipient-acceptances/{token}/accept`
- 거절: `POST /api/recipient-acceptances/{token}/decline`

#### **예외 처리**

만료·재사용 링크는 차단합니다. 이메일 변경 시 기존 수락을 무효화하고 재검증합니다.
