# 대기 기간 / 이의 제기

기능: 증빙 승인 후 7~30일 동안 작성자 취소와 제3자 이의 제기를 받아 오발송을 막습니다.
대상: 계획 작성자, 이의 제기 연락처
분류: Web Browser

#### **진입 조건**

외부 파트너가 공식 증빙을 승인하면 경고 이메일의 보안 링크로 진입합니다.

#### **표시 요소**

사후 사건 식별 정보, 예정 발송일, 남은 기간, 취소, 이의 제기, 문의와 피싱 안내를 표시합니다. 역할별 패키지 내용은 표시하지 않습니다.

#### **사용자 액션**

작성자는 본인 확인 후 전체 절차를 취소할 수 있습니다. 이의 제기 연락처는 사유와 증빙을 제출할 수 있습니다.

#### **API 호출**

- 상태 조회: `GET /api/release-cases/{caseId}/waiting`
- 작성자 취소: `POST /api/release-cases/{caseId}/cancel`
- 이의 제기: `POST /api/release-cases/{caseId}/disputes`

#### **예외 처리**

이의 제기 접수 즉시 자동 발송을 정지합니다. 분쟁 상태에서 운영자가 임의로 재개할 수 없도록 승인 절차를 분리합니다.
