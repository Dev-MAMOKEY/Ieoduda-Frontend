# 시스템 아키텍처 개요

기능: Next.js·Spring Boot·PostgreSQL이 사후 인계 상태를 관리하고 이메일·파트너·OpenAI API를 제한적으로 연계합니다.
분류: Definition

#### **Web Browser**

계획 작성자, 역할 담당자, 지정 확인자와 외부 파트너가 접근하는 반응형 웹입니다. 모든 알림은 이메일로 전달하고 실제 내용은 보안 웹 화면에서 확인합니다.

#### **Next.js — 프론트엔드 + BFF**

계획 작성, 역할 수락, 사망 신고, 증빙 제출, 파트너 검토, 대기·이의 제기와 사후 패키지 열람 화면을 제공합니다. 브라우저 요청을 Spring Boot로 중계하고 인증 쿠키를 관리합니다.

#### **Spring Boot — API + 상태 머신**

회원 인증, 객체별 권한, 계획 버전, 확인자 2인 신고, 파트너 검토, 대기 기간, 단계 발송, 반송·재시도·대체 담당자와 감사 로그를 관리합니다.

#### **PostgreSQL**

계획, 원문, 역할, 수락, 의존 관계, 사후 사건, 증빙 검토 결과, 이메일 발송과 접근 감사 기록을 저장합니다.

#### **암호화 증빙 저장소**

공식 증빙 원본을 파트너 검토에 필요한 기간만 암호화해 저장하고, 검토 완료 후 30일 이내 삭제합니다.

#### **Transactional Email Provider**

역할 수락, 사망 신고, 대기 경고, 이의 제기, 사후 인계와 OTP 이메일을 발송합니다. SPF·DKIM·DMARC를 적용합니다.

#### **OpenAI API**

선택된 원문만 받아 구조화와 충돌 후보 제안을 수행합니다. 사망·증빙·권리 판정에는 사용하지 않습니다.
