# AI 구조화 결과 검토

기능: AI가 만든 대상·행동·역할·선행 조건을 원문과 비교해 확정합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

AI 구조화가 완료되면 진입합니다.

#### **표시 요소**

원문과 구조화 카드, 원문 근거, 승인·수정·기각 버튼과 확인 질문을 표시합니다.

#### **사용자 액션**

모든 항목을 직접 검토합니다. 승인 전에는 실제 계획이나 사후 패키지에 포함되지 않습니다.

#### **API 호출**

- 결과 조회: `GET /api/plans/{planId}/compilations/{id}`
- 항목 검토: `POST /api/plans/{planId}/items/review`

#### **예외 처리**

근거 없는 항목과 금지 행동은 승인할 수 없습니다.
