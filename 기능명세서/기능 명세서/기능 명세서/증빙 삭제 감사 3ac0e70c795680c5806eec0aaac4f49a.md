# 증빙 삭제 감사

기능: 검토 완료 후 30일 이내 증빙 원본 삭제 여부를 추적하고 증명합니다.
대상: 서비스 운영자, 외부 법무·장례 파트너
분류: Web Browser

#### **진입 조건**

증빙 검토가 완료되면 삭제 일정이 생성되고 권한 있는 사용자가 조회할 수 있습니다.

#### **표시 요소**

검토 완료일, 삭제 예정일, 삭제 상태, 실제 삭제 시각, 무결성 해시와 실패 사유를 표시합니다. 삭제 후 원본 미리보기는 제공하지 않습니다.

#### **사용자 액션**

자동 삭제 실패 시 재처리를 요청하고 보안 사고 절차를 시작합니다.

#### **API 호출**

- 삭제 상태: `GET /api/evidence/{evidenceId}/deletion-status`
- 삭제 재처리: `POST /api/evidence/{evidenceId}/deletion-retry`

#### **예외 처리**

30일을 초과한 미삭제 증빙은 보안 경보로 처리합니다. 법적 보존이 필요한 경우 근거와 승인자를 별도 기록합니다.
