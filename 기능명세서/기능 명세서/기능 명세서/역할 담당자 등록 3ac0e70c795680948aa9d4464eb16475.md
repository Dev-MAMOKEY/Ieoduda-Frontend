# 역할 담당자 등록

기능: 가족·관계·업무 담당자와 대체 담당자의 이메일을 등록합니다.
대상: 계획 작성자
분류: Web Browser

#### **진입 조건**

구조화 항목이 승인된 후 진입합니다.

#### **표시 요소**

역할명, 담당자 이름, 이메일, 공개 범주, 최대 단계 대기 시간과 대체 담당자 입력을 표시합니다.

#### **사용자 액션**

담당자와 대체 담당자를 등록하고 역할 수락 이메일을 발송합니다.

#### **API 호출**

- 담당자 등록: `POST /api/plans/{planId}/recipients`
- 역할 수락 요청: `POST /api/recipients/{recipientId}/acceptance-email`

#### **예외 처리**

수락하지 않은 담당자는 실제 발송 단계에 포함할 수 없습니다. 이메일 중복 역할은 공개 범위를 다시 확인합니다.
